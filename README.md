# Accessibility Resources

Finished talks and materials on accessible course media.

**View online:** https://gerrypedraza.github.io/accessibility/

## Presentations

- [Accessible Media: Beyond the Checker](https://gerrypedraza.github.io/accessibility/presentations/accessible-media-overview/): why a document can pass an accessibility checker and still fail students. Open it in any browser; press **H** for the handout view (all slides on one page, printable) and **G** for the glossary.

The slides are plain HTML, built to be accessible: real headings and lists, alt text on every image, full keyboard control, and slide changes announced to screen readers.
